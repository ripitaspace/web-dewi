# Pustaka hero: asset status

Canvas 2560 × 1440 (16:9), scaled to cover the viewport. Pus and the board sit in a centred 3:2 safe area.
Source of truth: `scene-manifest.ts`. Layers live in `public/illustrations/pustaka/<group>/`.
Layers with `anchorX: "left"` are measured from the left edge of the screen, so they hug it at any aspect ratio.
`tilt` lays a layer back like a floor plane (used by the rug). Prompts for generating assets: `docs/pustaka-asset-prompts.md`.

## Gotchas
- Next's dev image cache is keyed by URL: if you replace an image, give it a new file name (and set `src` in the manifest) or clear `.next/cache/images`.
- Only the first image per chat turn reaches disk reliably: send assets while the assistant is idle.

## Motion
`pustaka-hero.tsx`: GSAP ScrollTrigger scrub over a 400vh track. Board + hands + text scale as one group from the board centre; Pus body and wall drift; a paper-coloured cover fades in; page content follows. `prefers-reduced-motion` skips the animation.
